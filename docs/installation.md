# 安装与首次使用

[English](installation.en.md)

## 准备

- Decky Loader。
- 可用的 LLM API（接口地址、API Key 和模型）。

模型服务可能收费，连接测试也会发起一次短请求。语音模型在需要时另外下载。

当前尚未绑定公开发行仓库。发行后只从本项目 Releases 下载 `deck-agent-X.Y.Z.zip` 和同名 `.zip.sha256`；Source code ZIP 不能安装。可在下载目录中运行 `sha256sum -c deck-agent-X.Y.Z.zip.sha256` 核对校验值（把 X.Y.Z 换成实际版本）。

## 安装

1. 结束现有任务、录音和待确认请求。
2. 打开 Decky 设置，启用开发者选项，选择下载好的本地 ZIP 文件安装。各版本按钮名称可能不同。
3. 打开插件「关于与更新」，核对版本。遇到加载问题先重载插件或重启 Decky，再查看 [调试说明](debugging.md)。

普通使用不要求开启 SSH、CEF 或安装开发工具。

## 第一次完成任务

1. 添加供应商、API Key 和模型，运行连接测试。自定义接口须与所选供应商协议兼容。
2. 在桌面模式先建立专用测试目录，例如 `~/DeckAgent/test`，在新会话中选择该目录。
3. 尝试：“请在当前目录创建 hello.txt，内容为 Hello Deck，然后读取它确认。”确认文件和回复符合预期。
4. 熟悉停止、切换会话和草稿恢复后，再使用自己的工作目录。

Agent 的文件权限不受当前工作目录限制；“只处理这个目录”的提示不能替代权限隔离。

## 语音

在「语音输入」选择模型和下载来源，等待逐文件校验完成，再选择麦克风。语音权重单独下载，占用额外磁盘空间。录音结束后在本地转写，文字填入草稿，不会自动发送。

模型体积、识别语言和下载空间以界面为准。当前没有完整的 Deck 模型速度、耗电与游戏帧率对比，使用前可先在空闲状态试录一小段。

## 更新

1. 在「关于与更新」填写本项目的 `owner/repo`（正式仓库确定后会在首页公布）。
2. 检查更新并阅读说明，点击「下载更新」，等待 SHA-256 和安装包校验通过。可取消下载或失败后重试。
3. 结束任务、录音和待确认请求，点击「安装已下载的更新」，在 Decky 原生弹窗中确认。安装确认期间不要启动新任务。
4. 核对版本，检查原有会话、供应商设置和语音模型。

发布版本缺少 `.zip.sha256` 校验文件时不支持插件内下载。Decky 安装接口不可用时，可通过「手动安装」打开发布页，下载 ZIP 后按首次安装的方法操作。下载缓存只在当前插件运行期间可直接安装，重启后需要重新下载。

更新检查优先返回正式版；仓库还没有正式版时会查找带安装包的公开测试版。已有正式版后，不会自动切换到更高的预发布版。仓库为空、未公开或被 GitHub 限流时，按界面提示处理。

更新不会主动覆盖 Decky 独立目录中的数据，但仍建议在重要更新前备份 `~/homebrew/settings/deck-agent/` 和 `~/homebrew/data/deck-agent/`；备份含密钥与会话，请妥善保管。

## 卸载与恢复

在 Decky 设置中卸载插件。插件自身的卸载逻辑保留配置、会话和模型，Decky 的数据清理行为可能随版本变化。需要恢复时重新安装插件并检查原有数据。

若要完全清除数据，先退出插件并自行备份，再检查 settings、data、logs 中的 `deck-agent` 目录。删除这些目录会丢失密钥、会话、模型或日志；这里不提供一键删除命令。

## 已知限制

- 首发以 OLED、已记录的 SteamOS / Decky 环境为验证范围，LCD 和其他组合待测试。
- 手柄、中文软键盘、语音质量、休眠与游戏运行时的体验仍需完整验收。
- 游戏 overlay 内可能需要返回 Steam 主界面后进入完整页。
- Git、uv、系统库和 TUI 专属扩展的兼容性取决于设备环境。
- 停止不撤销已写入的文件，也不能保证消除所有外部命令影响。
- 语音可以本地识别；在线模型任务仍需要网络。

## 出问题时

先记录版本、发生时间、复现步骤和错误提示。可以在 Deck 的 Konsole 运行：

```sh
bash ~/homebrew/plugins/deck-agent/resources/deck-diagnose.sh
```

诊断输出可能含主机名、局域网地址、路径、进程参数和日志，分享前自行检查遮盖。不要上传 `auth.json`、完整数据目录或私人会话。更多方法见 [调试说明](debugging.md)。
