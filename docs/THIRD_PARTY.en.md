- Pi 1.5.0: [earendil-works/pi](https://github.com/earendil-works/pi/tree/v1.5.0), MIT. Distributed as pinned npm packages with their licenses and required runtime dependencies, including internal TUI libraries; the product does not offer a TUI entry point.
- Node 22.23.1: [official distribution](https://nodejs.org/dist/v22.23.1/). `runtime/node/LICENSE` retains Node and bundled dependency notices.
- sherpa-onnx 2.0.1: [official release](https://github.com/k2-fsa/sherpa-onnx/releases/tag/v2.0.1), Apache-2.0; see [retained license](../resources/licenses/sherpa-onnx-LICENSE).
- ONNX Runtime: included by the sherpa-onnx runtime above, MIT; see [retained license](../resources/licenses/onnxruntime-LICENSE). The previously inspected bundled library reported version 1.28.2.
- SenseVoice Small INT8: [converted model](https://huggingface.co/csukuangfj/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17). The [original model card](https://huggingface.co/FunAudioLLM/SenseVoiceSmall/raw/main/README.md) specifies the [FunASR model license](https://github.com/modelscope/FunASR/blob/main/MODEL_LICENSE), version 1.1 at the recorded review. It includes source/author/model-name retention and other terms; read the full agreement rather than applying the code repository's MIT license to weights. The pinned conversion repository's LICENSE also points to FunASR terms. Weights are not bundled; new downloads use a fixed commit and per-file hashes. The legacy archive is retained only for migration verification.
- Whisper Small/Base INT8: converted [Small](https://huggingface.co/csukuangfj/sherpa-onnx-whisper-small) and [Base](https://huggingface.co/csukuangfj/sherpa-onnx-whisper-base) models. [OpenAI's official notice](https://github.com/openai/whisper#license) licenses original code and weights under MIT, requiring copyright/license retention. The pinned conversion roots did not list independent LICENSE files; additional declarations were not confirmed. Weights are not bundled; downloads use fixed commits and per-file hashes.
- Paraformer Chinese/English/Cantonese INT8: [converted model](https://huggingface.co/csukuangfj/sherpa-onnx-paraformer-trilingual-zh-cantonese-en). The [official ModelScope API](https://www.modelscope.cn/api/v1/models/dengcunqin/speech_seaco_paraformer_large_asr_nat-zh-cantonese-en-16k-common-vocab11666-pytorch) and [original README](https://www.modelscope.cn/api/v1/models/dengcunqin/speech_seaco_paraformer_large_asr_nat-zh-cantonese-en-16k-common-vocab11666-pytorch/repo?Revision=a63221070fd8baa970d841ceea59edfc1188a1ac&FilePath=README.md) both explicitly declare Apache License 2.0 for this specific original model (checked 2026-11-04). The conversion repository provides no separate LICENSE or additional license declaration. Weights are not bundled; downloads use a fixed commit and per-file SHA-256 checks.
- Optional [hf-mirror](https://hf-mirror.com/) downloads use the same repositories, revisions, and checksums as Hugging Face.
- Decky API 1.1.3: [loader-api](https://github.com/SteamDeckHomebrew/loader-api), BSD-3-Clause; see [retained license](../resources/licenses/decky-api-LICENSE). Decky UI comes from the host; Decky Loader itself is not copied into the package.
- Markdown: [react-markdown](https://github.com/remarkjs/react-markdown) 10.1.0 and [remark-gfm](https://github.com/remarkjs/remark-gfm) 4.0.1, MIT. See [retained dependency notices](../resources/licenses/markdown-dependencies-LICENSES.txt).

Project-owned source is licensed under the root [MIT license](../LICENSE). npm runtime dependencies retain their own licenses in their package directories; bundling does not relicense them. Model-license declarations were checked on 2026-11-03 and 2026-11-04. Model weights and runtime code follow their respective licenses.

- Ludusavi 0.31.0: downloaded on demand from its [official release](https://github.com/mtkennerly/ludusavi/releases/tag/v0.31.0), not bundled; MIT. Fixed SHA-256 values verify the Linux x64 archive and official legal.zip. The legal archive is retained in plugin data.
