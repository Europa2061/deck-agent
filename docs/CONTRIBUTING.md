# 参与 Deck Agent

[English](CONTRIBUTING.en.md)

欢迎反馈安装问题、兼容性结果、文档改进和代码修复。当前优先提高安装成功率与真机体验，较大功能请先开 Issue 说明用途和范围。

## 提交问题

选择 Bug 或功能建议模板，提供插件、SteamOS、Decky 版本，以及最短复现步骤。UI 问题请说明是在桌面开发页、Steam 主界面还是游戏 overlay 中发生；浏览器检查和实体手柄测试应分别说明。

分享前检查日志和截图，切勿附 API Key、认证文件、个人会话或游戏存档。安全问题见 [SECURITY.md](SECURITY.md)。

## 本地开发

按 [开发与构建](development.md) 安装锁定依赖。个人配置和实验数据保存在被忽略的 `.dev-data/`，不要放进源码或测试夹具。

提交前运行：

```sh
npm run typecheck
npm run test:frontend
npm run build
npm test
```

涉及发行包时还需在 Linux x64 准备运行时并运行包冒烟与 Decky 兼容检查。涉及界面、焦点、语音或休眠的变更请写明实际验证环境；无法测试的项列为待验证。

## 提交改动

- 保持改动聚焦，说明解决的问题、实际行为和验证范围。
- Git 提交标题和正文均包含中英双语，中文在前、英文在后，含义保持一致。
- 保留第三方来源和许可证，新增依赖说明用途。
- 使用真实配置的请求可能计费；可重复测试优先用临时目录和现有 faux 测试模型。
- 每次打包按项目约定升级版本，发布流程见 [发布说明](releasing.md)。

提交代码即表示你有权按本项目 MIT 许可提供该贡献；第三方内容请单独标明来源及其许可。
