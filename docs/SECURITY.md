# 安全问题

[English](SECURITY.en.md)

本项目仍处于早期测试阶段，目前仅维护最新源码和最新发行版，不承诺为历史版本提供安全修复。

## 报告方式

**普通 Bug、安装问题和功能建议，请直接提 Issue。**

如果发现可能泄露数据或绕过权限的漏洞，优先使用仓库 Security 页的 **Report a vulnerability** 私下报告。如果该入口未开启，可以先提 Issue 说明“希望私下报告安全问题”，不要附漏洞利用细节、密钥或私人数据。

报告时提供受影响版本、环境、问题影响，以及使用临时文件的最小复现。凭据已泄漏时，请先在供应商处撤销或轮换。当前仅维护最新版本，暂不承诺固定响应时间。

## 使用边界

Agent 具有文件和命令能力，运行用户权限、工具执行和扩展来源都影响安全。项目不提供系统沙箱或通用操作审批保证。详情见 [权限与隐私](privacy.md)。
