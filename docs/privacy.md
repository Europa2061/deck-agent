# 权限、数据与隐私

[English](privacy.en.md)

本文描述仓库当前实现，不替代你选择的模型供应商和扩展各自的条款。

## Agent 可以做什么

Pi 可以调用文件和命令工具，权限取决于其运行用户。插件不请求 root，也不自动用 sudo 安装系统依赖；这不构成系统沙箱，工作目录之外的可访问文件也可能被读取或修改。

插件沿用 Pi 的工具和扩展行为，没有新增一套“所有危险操作都必须确认”的审批机制。扩展弹出的确认框不能代表所有命令都会先询问。停止任务不会回滚已完成的操作。

## 哪些内容会联网

| 操作 | 连接对象与数据 |
| --- | --- |
| 连接测试、聊天与执行任务 | 用户配置的供应商接收认证信息、相关对话，以及进入模型上下文的文件或工具结果；范围由 Pi、模型与扩展决定 |
| 下载语音模型 | Hugging Face 或用户选择的 hf-mirror；服务可见 IP 和下载请求，文件按固定版本校验 |
| 检查和下载插件更新 | GitHub API 与 Release 下载地址，包含仓库及安装包请求；不需要发送聊天正文或模型 API Key |
| Skills、扩展、MCP 和外部命令 | 由对应工具决定，可能访问其他网站或服务；安装前自行核对来源 |

插件当前没有主动上传使用统计的功能。上述正常网络请求仍由接收服务按自身政策处理。本地语音转写完成后，点击发送会把文字交给配置的模型。

## 设备上保存什么

常见 Decky 路径如下，实际以诊断显示为准：

| 目录 | 内容 |
| --- | --- |
| `~/homebrew/settings/deck-agent/` | 插件设置；`pi/` 中的认证、模型与扩展配置 |
| `~/homebrew/data/deck-agent/` | 会话历史、元数据、新会话草稿、语音模型、下载缓存、临时录音与更新包 |
| `~/homebrew/logs/deck-agent/` | 插件轮转日志，当前最多约 15 MB |

凭据以本地文件保存，写入权限为 `0600`，不是加密保险箱；同权限进程、可信扩展和有更高权限的用户仍可能读取。备份也可能包含明文凭据。

录音在转写或取消后清理；异常退出后可能残留临时文件。会话和草稿会持久保存；更新代码不主动清除这些数据。语音模型下载取消可能保留半包，便于续传；更新包下载取消或失败会删除未完成文件。

## 日志与反馈

插件日志设计上不记录完整对话、命令参数、工具输出或语音正文，并隐藏已登记密钥。第三方错误、进程输出和诊断信息仍可能带入私人路径等信息，不能保证自动脱敏覆盖所有情况。

提交 Issue 前检查日志、录屏和截图，遮盖密钥、用户名、私有路径、主机名、IP、供应商私有地址和会话内容。不要上传认证文件或整个 settings/data 目录。发现疑似凭据泄漏后先在供应商处撤销凭据，再报告。


## 内置玩家工具

玩家工具的操作记录、Mod 安装归属、原文件备份、插件请求和按需安装的 Ludusavi 放在 Decky 数据目录的 `deck-agent/player-tools/`。存档和配置备份可能含个人数据，模型读取的工具结果仍会进入你选择的供应商上下文。

Mod 网页检索向 Bing 发送搜索词，GitHub 检索与发行查询访问 GitHub。读取作者网页、下载 Mod、插件和 Ludusavi 会连接对应来源。搜索词应只包含游戏和需求，不包含私人日志或本机凭据。

这些专用工具在配置修改、恢复备份、部署/启停 Mod 前请求 GUI 确认；插件安装由 Decky 原生弹窗确认。这些检查只覆盖专用工具，Pi 的原生命令与扩展仍有各自行为，并非全局审批或沙箱。
